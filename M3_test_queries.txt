--------------------------------------------------------------------------------
3. WHAT WE CHANGED IN MILESTONE 3 (code changes in search.py)
--------------------------------------------------------------------------------
All changes are general heuristics applied as multipliers after lnc.ltc cosine
scoring, so the IR core is unchanged.

  (1) JUNK_URL_PATTERNS (score *= 0.1)
      Penalize URL shapes that are usually non-content: image detail views,
      xmlrpc.php, Apache ?C=N;O=A directory-sort links, login/edit/diff pages,
      numbered single-slide pages (tsld/sld/slideNNN), and frame container pages.
      Fixes junk-at-#1 problems for queries (1)-(5) above.

  (2) IMPORTANT_BOOST lowered from 2 to 1
      Title/heading/bold terms still get extra weight via imp_tf, but a smaller
      boost stops 10-word slide pages from looking as strong as full articles.
      Works together with (3) for queries (6)-(9).

  (3) Short-document penalty (score *= 0.6 when lnc doc length < 1.5)
      Demotes pages with only a handful of distinct tokens (stubs, slides).
      Helps queries (6)-(9) and reduces frameset dominance for (8).

  (4) URL term-match bonus (up to 1.30x, capped at 2 matching query terms)
      If a stemmed query term appears in the URL path, boost the score — strong
      signal that the page is "about" that entity. Helps queries (10)-(14).

  (5) URL quality prior (~0.80-1.08x)
      Mild bump for root/index URLs; mild dampening for very deep paths. Helps
      program/org home pages rank first for queries (15)-(17).

Indexer (unchanged for M3 report scope, but required for developer option):
  Partial indexes spilled every 10,000 documents, streaming k-way merge to
  inverted_index.jsonl + index_offsets.json; URL and exact-content dedup plus
  SimHash near-duplicate removal during indexing.

Search efficiency (developer option):
  Index never fully loaded; one disk seek per query term via offset map; AND
  implemented by intersecting per-term doc-id sets. All 28 queries < 300 ms.
